AUTHORITATIVE CONTEXT

One identity for every monitored asset.

Monitoring tells you what happened. The SSOT identifies the device, its owner and the service it supports.

AssetService / ownerSensor mappingAuthority / verified

Explicit mappings. No guessed identity.

Import a reviewed export from Nautobot, NetBox or your asset register using this schema. Each PRTG sensor ID maps to one asset and an exact channel name and unit. Unmapped, duplicated or stale records stop live runs.

Facts and monitoring readings remain separate. Sample records are labelled and must be replaced before a live run. Direct Nautobot / NetBox synchronization is not included in this version.
